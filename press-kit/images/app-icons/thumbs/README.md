# App icon previews

96 × 96 PNG previews of the [app icons](../), for embedding in pages such as these READMEs. They are generated by `scripts/generate_assets.py` from the 1024 px masters, so don't edit them by hand.

For print, articles, or listings, use the full-size icons in [`app-icons/`](../).
