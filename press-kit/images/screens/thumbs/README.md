# Product screen previews

300 px wide JPEG previews of the [product screens](../), for embedding in pages such as these READMEs. They are generated by `scripts/generate_assets.py` from the full-size files, so don't edit them by hand.

For articles or listings, use the full-size screens in [`screens/`](../).
