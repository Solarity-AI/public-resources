# Brand

Solarity AI's visual identity, as used on [solarityai.com](https://solarityai.com/).

| Folder | What's there |
| --- | --- |
| [`logos/`](logos/) | The sun mark in several sizes, transparent and on dark |
| [`banner/`](banner/) | Wide banners for headers and social profiles |
| [`colors/`](colors/) | The color palette with HEX and RGB values |
| [`typography/`](typography/) | Typefaces and how they are used |
| [`social-media/`](social-media/) | Official social channels and the default share image |
| [`brand-guidelines/`](brand-guidelines/) | Rules for using the name, mark, and descriptions |

**The rules in brief:**
- Write the name as **Solarity AI**: two words, with "AI" in capitals.
- Use the sun mark as supplied. Don't recolor, stretch, or redraw it.
- Describe products only with the facts on [solarityai.com](https://solarityai.com/).

Full rules are in [`brand-guidelines/`](brand-guidelines/).
