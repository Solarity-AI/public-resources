# Security policy

## Reporting a vulnerability

If you find a security issue, report it privately. That covers this repository, solarityai.com, the Solarity AI apps (Looks Max, IQ Max, Sleep Max, Fitness Max, listed as Only Fitness), and the SaaS products (Engineering Max, Management Max, Marketing Max).

- **Preferred:** [report it privately on GitHub](https://github.com/Solarity-AI/public-resources/security/advisories/new)
- **Email:** [ata.turhan@solarityai.com](mailto:ata.turhan@solarityai.com) with the subject `Security report`

Please include:

- The affected product, URL, or file
- Steps to reproduce the issue
- Its impact, and any proof of concept

**Do not** open a public issue for security problems.

## What to expect

- We'll confirm we received your report within **3 business days**.
- We'll keep you updated until the issue is resolved.
- If you'd like, we'll credit you once a fix ships.

## Out of scope

- Reports from automated scanners with no demonstrated impact
- Missing security headers with no demonstrated impact
- Social engineering, physical attacks, and denial-of-service testing

This repository holds documents and images, plus a few Python scripts that check them and build the press kit; nothing here runs as a service. If you find credentials or other sensitive data committed here by mistake, please report it.
