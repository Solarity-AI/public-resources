# SaaS products: one-pager

**The app factory.** Three SaaS products for the engineering, management, and marketing work behind mobile products, built alongside Solarity AI's own apps. All three run on the web today and are in early access. Mobile versions are planned.

| Stage | Product | Built for | Plans |
| --- | --- | --- | --- |
| Build | **[Engineering Max](https://engineeringmax.solarityai.com/)** | App engineering: find and fix what keeps a mobile app out of the App Store. | Free during early access. Pricing is not set yet. |
| Operate | **[Management Max](https://managementmax.solarityai.com/)** | Metrics for app portfolios: governed weekly metrics for mobile app companies. | Free for 1 app and 2 seats, with paid plans for larger portfolios. |
| Grow | **[Marketing Max](https://marketingmax.solarityai.com/)** | Short-form video marketing: your next Reel, made from one that already worked. | Pricing is not set yet. |

## Engineering Max

Your own Claude Code or Codex writes a read-only report on the app, without sharing source code. Engineering Max checks that report against 155 rules across 12 areas, ranks the problems, and returns one focused fix prompt at a time. Then it checks each fix.

- 155 rules across 12 areas, with store blockers and security first
- Works with Expo, React Native, Flutter, and native apps
- Reads the agent's report, never the source code
- Tested first on Solarity AI's own Sleep Max

## Management Max

Holds a company's weekly metrics for each app, checks every figure as it comes in, and combines them across any selection of apps. Where combining would be misleading, it shows the spread instead and says why.

- 50 metric definitions and 16 validation rules
- Syncs from RevenueCat, AppsFlyer, App Store Connect, Google Play, Firebase, GitHub, and YouTube
- Roles for the whole team, and every change is signed
- Paid plans count apps, not seats

## Marketing Max

Finds the Reels that performed, writes the caption and the on-screen line in the brand's voice, and posts to Instagram at the chosen time. A person approves each of the 4 steps.

- Built for Solarity AI's own apps first
- 4 recorded approvals: video, reason, caption, and send
- Line tests and results for every post
- Instagram today, with TikTok and YouTube Shorts planned
